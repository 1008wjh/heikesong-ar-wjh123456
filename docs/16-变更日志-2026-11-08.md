# 变更日志 · 2026-11-08（录音与渲染修复）

> 给人和 AI 都能读的版本。人类看“摘要 + 明细”，AI 看 front matter 和
> `<!-- AI-READABLE -->` 里的 JSON 索引；命令都可以直接复制执行。

## 1. 人类摘要

这一版只解决三件事，**不碰 ASR**：

1. **录音不再 55 秒断、不再被 30 秒截断**：按官方 `input.audio` 会话契约改成
   “`finish()` → 抽干 `end` → 再开新会话”；切片 WAV 按实际字节数生成；
2. **模拟器不再满屏 “Text”**：所有 Text 显式初始化，空文本用空格占位，不再依赖
   `setText("")` 的默认值；
3. **字不再闪**：`putText()` 加写值缓存，去掉每次更新都 `setSize()` 的重排；
   每 400ms 的 `paintListening()` 现在只在内容变化时真正写控件。

顺带补了模拟器一键脚本 `tools/open_sim.ps1`、SDK 审查文档和本变更日志。

## 5. 兼容性与风险

- 录音状态机依赖官方 `end` 事件；如果平台在 1.5 秒内不给 `end`，停止时会
  按超时用已收音频收尾（不会卡死）。
- 会话轮换期间有毫秒级空档；切片仍按 15s/55s 目标触发，允许 ±1 帧误差。
- `putText()` 空串写空格；如果后续需要真正隐藏控件，可换 `setHidden(true)`，
  但不影响当前显示。
- 本版**没有**接 ASR：转写仍走 `src/llm.py` 的 local/http 通道，后续再接听悟或本地模型。
- 真实麦克风端到端还要在 WSLg 音频恢复后点一次“单人/多人 → 开始”验证；
  `pactl list short sources` 有 `RDPSource` 时说明 WSLg 麦克风存在。
