# 变更日志 · 2026-11-08（在 2.9.9/55 上重放录音与闪烁修复）

> 这份是给人和 AI 都能读的版本。人类看“摘要 + 改动 + 验证”，
> AI 先读 front matter 和 `<!-- AI-READABLE -->` 的 JSON。

## 1. 摘要

远端 `main` 已经是 `00d1e61`（2.9.9 / 55，22 个新提交）。本分支以它为基线，
只重放三组还没有被远端覆盖的修复，**不碰 ASR**：

1. **55 秒切片不再被 30 秒截断**：`MAX_SAMPLES` 改成 60 秒；
   `toWav()` 用实际 chunk 字节数，WAV 头与数据一致。
2. **字不再闪**：`putText()` 加写值缓存，去掉每次更新都 `setSize()`；
   空字符串统一写成空格，避免回落到默认 “Text”。
3. **会话切换/停止不丢尾音**：`closeSession()` 不再先 `cancel()`（会丢弃排队音频），
   改为 `finish()` 后把 audio 收进当前切片、把 `end` 读走；停止时 `await`
   收完再组 WAV；59 秒轮换等旧会话回收后再开新会话。

## 3. 改动明细

| 文件 | 改了什么 | 为什么 |
|---|---|---|
| `glasses/src/index.js` | `MAX_SAMPLES` 30s → 60s；`toWav()` 用实际字节数并偶数对齐 | 55 秒片不能被 30 秒截断；WAV 头长度必须等于 data |
| `glasses/src/index.js` | `putText()` 缓存 + 空串写空格；去掉 `setSize()`；直接 `setText` 全部改走 `putText` | 每 400ms 全量 `setText+setSize` 是字体闪烁源；默认占位是 “Text” |
| `glasses/src/index.js` | `closeSession(session, c, done)`：不 `cancel()`，`finish()` 后把 audio 收进 `c`，`end` 读走；`restartSession` 等 end 后延迟开新会话；`stopAndArchive` await 收尾 | 远端旧实现会丢排队音频，切会话/停止时尾音缺失；同时满足平台“先消费 end 再申请” |
| `glasses/FusionUIApp.json` | `2.9.9 / 55` → `2.9.10 / 56` | 包内容变化，versionCode 必须递增 |
| `dist/memorylens.fuiapp` | 重新打包（debug-unsigned） | 模拟器验证用 |

## 5. 兼容性 / 风险

- `closeSession()` 现在最多等 1.5 秒收尾；平台若给不出 `end`，停止会按超时用已收音频收尾。
- 59 秒轮换会在旧会话 `end` 后 300ms 再开新会话，期间有短暂空档（<1 秒）。
- 本分支**不包含** ASR；听悟/本地模型仍是下一步。
- 远端 main 已有自己的 `SenseVoice / WSLg PulseAudio / 音量条` 等改动，本分支只在其上重放上述三组修复，不回退远端功能。
