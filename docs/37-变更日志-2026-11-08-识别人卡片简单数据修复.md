## 现象

识别人返回了名字（马子轩）和身份（队友），但镜片上没有简单数据；控制台里 simple 是有的（`{"11":"22"}`）。

## 原因

`_voice_identify` 里匹配用的是：

```python
others = [p for p in store.voice_index() if p["id"] not in owner_ids]
```

`voice_index()` 是给声纹匹配用的**轻量视图**，只有 `id / name / role / voice_embeddings`，
没有 `simple` / `info`。命中后直接拿这个轻量 `person` 去 `cards.build_card()`，
自然只能画出名字和身份，简单数据全丢。

修：出卡前换成完整记录。

```python
full = store.get(person["id"]) or person
card = cards.build_card(full, sim_val, voice.THRESHOLD)
```

## 顺手修掉的第二个问题

用马子轩自己注册时保存的录音去识别，返回 `only_owner`（只听到你自己）。
原因：他的声纹和主人 wjh 的相似度有 **0.49**，主人剔除条件是 `sim_owner >= 0.45`，
于是他的簇被当成主人剔掉了。

改成"只有明显更像主人、且没有明显更像别人"才剔除：

```python
if owner_embs and sim_owner >= voice.IDENTIFY_THRESHOLD:
    if person is None or sim_owner > sim_val + voice.IDENTIFY_MARGIN:
        continue
```

这样：
- 主人自己的簇（sim_owner 0.576，别人 0.222）→ 剔除；
- 马子轩的簇（sim_owner 0.49，本人 0.974）→ 保留并认出。

## 说明

- 简单数据按 JSON 的键序逐行拼成 `"key: value"`，最多 4 行；没有 simple 时仍回退到
  role + info（老行为）。
- 声纹接近（0.49）说明马子轩的注册录音和主人的声线比较像；如果以后识别串号，
  优先重录更干净的 10 秒（一个人、别带别人说话）。
- 跑测试会还原 `data/people.json`，测试期间别在控制台改数据，避免被还原。
