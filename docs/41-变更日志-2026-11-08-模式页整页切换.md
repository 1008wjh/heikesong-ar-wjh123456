## 为什么再改一次

上一版（3.6.10）已经确认：方向键到了应用、`index` 变了、`paintMode` 在算 `【多人】`，
但镜片画面停在首帧；清缓存、隐藏/显示、RAF、`invalidate()` 都没让那几行 Text 重绘。

所以这次不再依赖「改文字」，改成**两套静态页面**，切换只动可见性：

- 页 A：`【单人】 / 多人` + 单人提示
- 页 B：`单人 / 【多人】` + 多人提示

上下键 = 显示页 A 或页 B；文字本身永远不变。

## 实现

- `buildHud` 预建两页静态 Text（隐藏）；
- `paintMode`：隐藏 `retained.info`，只显示 `retained.modePages[index]`；
- 返回 / 确认离开模式时 `showInfoRows()` 恢复 `retained.info`、隐藏两页；
- 模拟器的假 Text 补了 `setHidden/getHidden`，`hud()` 过滤隐藏控件。
