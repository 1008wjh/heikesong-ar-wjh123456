## 现象

双击 `sim.bat` → 黑框出现一两秒就关掉，什么都没看清。

## 根因

1. `tools/start-sim.ps1` 里的 Docker 检查是：

   ```powershell
   try { docker info --format '{{.ServerVersion}}' | Out-Null } catch { ... }
   ```

   Windows PowerShell 5.1 里**原生命令失败不会抛异常**（`$LASTEXITCODE` 才是结果），
   所以这个 `catch` 永远进不去。Docker Desktop 没在跑时脚本照样往下走。

2. 接着走到开窗口那步，`kit-docker.ps1 gui` 在 WSL 里执行 `docker run`，报：

   ```
   The command 'docker' could not be found in this WSL 2 distro.
   ```

   然后脚本 `exit`，窗口直接关掉 —— 就是你看到的闪退。

3. 所有失败分支只 `Write-Host` 不暂停，所以哪怕有提示也来不及看。

4. 顺带发现的坑：`$ErrorActionPreference='Stop'` 下，原生命令的 stderr 一旦被
   `*>` 重定向，PS 5.1 会抛 `NativeCommandError` —— 新加的 WSL 探测一开始因此
   永远返回 false。现在探测函数内部临时把 EAP 调成 `Continue`，只看退出码。

## 改法

- Docker 探测按退出码判断；没跑就用 `Start-Process` 拉起 Docker Desktop（最多等 2 分钟）。
- 引擎起来后再等 WSL Integration（最多 3 分钟）；超时直接告诉你去
  **Docker Desktop → Settings → Resources → WSL Integration → 打开 Ubuntu**。
- 模拟器镜像 `memorylens-irisview` 不存在时自动 build。
- 失败信息统一走 `Fail()`；`sim.bat` 在 `errorlevel` 非 0 时 `pause`，不会再一闪而过。
- 正常关掉模拟器 → `exit 0`，不会多要一次回车。
- 新增 `-CheckOnly`：只做环境检查、不开窗口，方便排查
  （`powershell -File tools\start-sim.ps1 -CheckOnly`）。

按 ANSI 读会把中文和引号读坏、直接语法错误（这也是"闪退"的一种可能）。
