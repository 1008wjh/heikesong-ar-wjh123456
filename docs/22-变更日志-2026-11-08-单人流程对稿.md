## 这轮按对稿改了 5 处

1. **识别人 20 秒**。`data/settings.json` 的 `identify_sec` 从 15 改成 20，眼镜上的
   「识别人 N/20」「录 20 秒来找人」改成跟着设置走，后台改时长界面不会再对不上。
   显式写了 `MEMORYLENS_IDENTIFY_MS` 时以环境变量为准（测试/演示用 9 秒）。
2. **先档案、后按钮**。认出人之后先单独显示 5 秒档案（名字 / 身份 / SIM / 三行信息），
   底栏写「先看档案 · 按钮 N 秒后出现」，5 秒后换成三个预设按钮；这 5 秒里按键仍然有效。
3. **按按钮就能问模型**。以前这段不足 1.5 秒音频会提示「再说两句再提交」；现在直接发一次
   不带音频的 `/api/agent/feed`，用「这个人的档案 + 这一段听到的话 + 按钮的提示词」问模型。
   实测 1.5 秒返回三条跟王姐档案相关的话（豆豆 / 报价单 / 周三前发）。
4. **主人声纹入口**。控制台人脉库顶部会出现提醒：「主人「wjh」还没录声纹：识别人时不会剔除
   你自己，容易被当成陌生人建号」，点一下直接打开主人的编辑页；主人那一栏的按钮文案是
   「录主人声纹（7 秒）」。录完之后 `/api/voice/identify` 才会真正剔掉主人那一簇。
5. **不再显示假 SIM**。`pinned`（按按钮追问）和自动建号的卡片没有真实相似度，
   以前会显示 `SIM 1.00`，现在留空。

## 工作流（现在的实际行为）

```
待机 → 确认 → 选「单人」→ 在听（只有「> 识别人」）
     → 确认 → 录 20 秒（再按一次可提前结束）
     → 服务端 diar 聚类 → 剔除主人簇（主人有声纹时）→ 和库里声纹比
     → 熟人：档案卡停 5 秒 → 三个按钮（提词 / 待办 / 以前）
        陌生人：自动建号「陌生人A」入库 → 同样出按钮
     → 按按钮：有声音就切这一片+按钮提示词问模型；没声音就拿档案+已听到的话问
     → 录音一直不停；返回 = 结束并入库
```
