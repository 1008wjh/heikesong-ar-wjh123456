### 两档数据怎么写的

**简单数据**（给镜片、让人一眼认出）：

```json
{"关系":"行业前辈","身份":"小米创始人","上次见面":"2026-09 大会","性格":"健谈、爱聊产品"}
```

- 只放 3–4 个最浓缩的字段：关系、身份、上次见面、性格；
- 最多一条「备注」（比如房东"每月 1 号交租"、Tony"别剪太短"），大部分人不带；
- 也有只给两三个字段的（老张只有 关系/身份/性格）。

**复杂数据**（只进回答模型的提示词，不上镜片）：

```json
{"工作":{"公司":"小米","方向":"手机 / 汽车 / 生态链"},
 "兴趣":{"运动":"跑步","口头禅":"感动人心"},
 "历史":["2026-09 大会后台聊了十分钟"],
 "计划":{"待办":"约 SU7 试驾"}}
```

每个人维度不同：工作/家庭/兴趣/健康/饮食/旅行/历史/计划/合同/教育/社交/禁忌…
比如房东是「合同 + 历史 + 备注」，牙医是「工作 + 健康 + 历史」，亲戚是「家庭 + 兴趣 + 历史」。
