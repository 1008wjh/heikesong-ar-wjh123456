## 1. 控制台「04 验收测试」

![验收测试页](selftest_page.png)

- 一键跑 **8 项验收用例 + 10 次连续延迟**，结果卡片（PASS/FAIL + 预期/实际/证据）直接展示；
- 跑完可「导出 JSON」，作为提交证据；
- 测试跑在**当前登录用户**的数据上；开始前快照 `people.json`，结束后还原并清 store 缓存，
  不会把演示库改脏；
- 延迟测的是**提词路径**（preset=hint，单次模型调用，含 HTTP 往返）：
  最近一次 p50 **1023ms**、p95 **1255ms**、8/8 通过、总用时 31 秒。

## 2. 可提交的测试包

`submission/test_kit/`（另有 `test_kit.zip`，约 700KB）：

| 文件 | 说明 |
|---|---|
| `README.md` | 怎么跑、8 项说明 |
| `run_selftest.py` | 登录 → `/api/selftest/run` → 保存 report.json → 打印汇总 + 阈值检查 |
| `expected.json` | 8 项预期 + 延迟阈值（p50 ≤ 2000ms、p95 ≤ 3500ms） |
| `samples/` | huihui_b（语音）、silence（服务失败）、constructed_meeting（双人会议） |
| `report.json` / `report.md` | 本次实际运行结果（8/8，p50 1057ms / p95 1317ms） |

复现：

```powershell
start.bat
python submission\test_kit\run_selftest.py
```

## 4. wjh 账号照片不显示

原因：按用户隔离后，首次创建 `data/users/<uid>/` 时只拷了 people/settings/presets，
**没拷 `photos/`**，所以 `photos/p_xxx.jpg` 找不到。

修复：建用户目录时把根 `data/photos` 复制到用户目录；已有用户目录为空也会补一次。
验证：wjh 登录后 `/api/people` 里里奥/奥巴马有 photo，`GET /api/photo?id=` 返回 `200 image/jpeg`。
