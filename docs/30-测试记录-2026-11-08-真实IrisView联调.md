## 发现的问题

### 1. `/api/latest` 的 `at` 单位错了（已修）

服务端写的是 `time.time()`（秒），眼镜端拿 `Date.now()`（毫秒）比较：

```js
if ((data.at || 0) < bootAt) return;          // 1.79e9 < 1.79e12，永远成立
```

所以**真实镜片从来不会因为轮询而更新**：`tools/say.py` 推卡片没反应，
第二段"晚到的旧卡"过滤也一直在误判。改成 `time.time() * 1000` 后，
say.py 推的卡片立刻出现在真镜片上（`live_lens_3.png`）。

> 之前 Node 仿真没暴露它，因为仿真里的卡片都来自 `/api/agent/feed` 的同步响应，
> 没走轮询渲染这条路径。

### 2. 没有麦克风时「识别人」会卡在 20/20（待决定）

`finishIdentify()` 只在 `pump()` 的音频分支里按时间触发：

```js
if (c.identifying) {
  c.identChunks.push(buf);
  if (Date.now() - c.identAt >= IDENTIFY_MS) finishIdentify(c);
}
```

模拟器没有麦克风（`live_lens_ident_b.png` 停在 `20/20`）；真机上如果麦克风被静音、
或者平台一直不给帧，也会出现同样的"卡住"。建议在 `pump()` 每拍末尾补一行：

```js
if (c.identifying && Date.now() - c.identAt >= IDENTIFY_MS) finishIdentify(c);
```

这样没声音时会正常收尾并提示「没录到声音」，而不是永远停在 20/20。
这行要动眼镜端并重新打包（3.5.5 / 77），**等你确认再改**。
