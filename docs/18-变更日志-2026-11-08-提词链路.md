## 这次改了什么

1. **第一片只回数据库**。认出人之后，镜片上是他档案里的内容（身份 + 几条信息），
   不再让模型生成一段总结。判断条件是 `slice_no <= 1 and not manual`。
2. **之后改成手动触发**。录音一直在走，但不再自动切片；你按一次确认，才把这一段
   交给智能体，把「他的档案 + 刚才这段」拼成提示词，给出三条能直接说出口的提词。
3. **提词停在在听页上 20 秒**。状态行继续走计时和波形，下面三行不动；20 秒后收起。
4. **两个真 bug**：
   - `paintListening()` 定义不带参数，`manualAsk()` 传的提示被静默丢掉；
   - `pushChunk()` 没设 `c.showUntil`，卡片画出来不到 1 毫秒就被 `paintListening()` 刷掉。

## 怎么验证

```powershell
node test\glasses_sim.js      # 含「提词显示在在听页上（卡片没有被刷掉）」
python tools\say.py "王姐：报价单我下周三前发你" --manual
```

`say.py` 会打印 state / person / rows / options；镜片侧应看到 `在想…` → 三条提词。
