## 现象

双击 `sim.bat` 报：

```
[..] looking for the IrisView developer kit in WSL...
[!!] Developer kit not found in any WSL distro. Run the IrisView installer, or pass IRIS_KIT / use tools\kit-docker.ps1.
```

## 原因

队友把启动脚本改成了 **WSLg 原生模式**，只在 WSL 的这几个目录找 kit：

```
/home/iris/IrisView/Developer-Kit
/home/ubuntu/IrisView/Developer-Kit
/opt/IrisView/Developer-Kit
```

这台机器的 kit 在 `E:\ar-memory\IrisView-Developer-Kit-v1.0.0-LLVISION-v2\...`，
所以第一步就失败了。之前能跑的是 Docker + WSLg 的 `kit-docker.ps1 gui`。

## 改法

`tools/start-sim.ps1` 在 WSL 找不到 kit 时不再直接退出，回退到 Docker 路径：

1. 检查 Docker 是否在跑（没跑就明确提示启动 Docker Desktop）；
2. 检查/拉起后端（`start.bat`）；
3. 包比源码旧就 `kit-docker.ps1 build` + `package`；
4. `kit-docker.ps1 gui`：Docker 里跑模拟器，窗口经 WSLg 显示到 Windows。

WSL 里装了 kit 的机器仍走原来的 WSL 原生流程，不受影响。

## 验证

```
cmd /c "sim.bat -CheckOnly -NoBackend"
  [..] no IrisView kit in WSL; trying Docker + WSLg fallback...
  [ok] environment check passed (Docker / image / backend / package)
```

完整启动：

```
cmd /c "sim.bat -NoBackend"
  memorylens-sim 容器 Up
  LLVISION Agent Platform 窗口正常显示（WSLg）
  [boot] MemoryLens glasses app ready
```

关掉窗口即结束；容器名 `memorylens-sim`，残留时可 `docker rm -f memorylens-sim`。
