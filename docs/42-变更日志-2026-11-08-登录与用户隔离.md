## 登录页

![登录页](auth_login.png)

- 地址 `/login.html`；登录后进控制台，右上角显示用户名 + 退出（截图见 `auth_console.png`）；
- 演示账号：
  - `demo / demo123`（演示用户）
  - `guest / guest123`（访客）
  - `wjh / wjh123`
- 账号存 `data/users.json`，PBKDF2-SHA256 哈希 + 每用户 salt；
- JWT 是标准库实现的 HS256（不引第三方），密钥落 `data/.jwt_secret`，有效期 12 小时。

## 接口保护

- 除 `/api/health`、`/api/auth/login` 和静态文件外，`/api/*` 都要 `Authorization: Bearer <token>`，否则 401；
- 眼镜端没有登录页：`/api/latest`、`/api/agent/feed`、`/api/agent/archive`、`/api/agent/cancel`、`/api/voice/scan`、`/api/voice/identify` 不带 token 也能用，按**最近一次控制台登录的用户**处理（没登录过就是 demo）；
- 控制台的 `fetch` 统一加 Bearer，收到 401 自动清 token 回登录页。

## 数据隔离

每个用户一个目录：

```
data/users/<uid>/
  people.json      人脉库
  settings.json    设置（hold_sec / system_prompt…）
  presets.json     快捷按钮
  voiceprints/     注册声纹录音
  meetings.db      会议库（SQLite，按用户）
  meetings/        会议归档
  audio_storage/   会议音频
```

- 第一次登录时从根 `data/` 复制模板（当前 56 人库、设置、预设）；
- 请求进来用 ContextVar 标记当前用户；`store` 换成按用户转发的 Proxy，settings/presets/会议路径也跟着走；
- `AR_AUTH_DISABLED=1` 时不做隔离，直接用根 `data/`，旧测试/脚本行为不变。

## 注意

- `data/users/`、`data/users.json`、`data/.jwt_secret` 已加 .gitignore（用户数据和密钥不进仓库）；
- 根 `data/people.json` 现在只是**新用户的模板**；已有的 56 人库会复制给每个新用户；
- 演示版没有做刷新 token、登出吊销、限流；token 泄露风险按现场演示处理。
