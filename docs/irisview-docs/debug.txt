浏览接口调试与诊断
根据故障发生的阶段选择日志：环境检查、安装、应用运行或模拟器显示。
选择显示与运行模式
mono | 640 × 480，显示左眼。 | 
stereo | 1280 × 480，左右眼并排。 | 
normal | 默认使用 release。 | 
analysis | 未显式指定 profile 时使用 diagnostic；不等于授予应用信任。 | 

先关闭当前 Client，等待终端返回提示符。在 Ubuntu 终端中设置 KIT 为 Kit 根目录、PACKAGE 为待运行 .fuiapp 的完整路径，再执行以下命令。显示模式控制单目或双目输出，profile 控制诊断配置，两者独立。
复制"$KIT/bin/irisview" run "$PACKAGE" --allow-debug-unsigned --client-mode analysis --display-mode mono
# 会话结束后，查询对应 profile
"$KIT/bin/irisview" state path --profile diagnostic
"$KIT/bin/irisview" state status --profile diagnostic
找到本次日志
查询结果中的 profileStateDirectory 指向状态目录，logs 保存日志。完成后的 run 回执会列出 clientLogs 与 simulatorLog。指定过自定义 --state-dir 时，到该目录查找本次输出。
按症状检查
没有窗口 | 检查 Ubuntu 图形桌面 / WSLg、主机依赖和启动错误。 | 
空白 Client | 确认 run 带了包路径，或在已安装列表选择并启动应用。 | 
宣传图不变 | 打开独立模拟器；Client 宣传图不是实时预览。 | 
安装拒绝 | 检查签名信任、ID、versionCode 和包完整性。 | 
资源加载失败 | 检查图片路径、加载结果、原始日志与复现条件。 | 

诊断数据的含义
Health 提供汇总值，Lite Trace 记录采样窗口内的事件。缺失指标标记为“不可用”。逐帧分位数和最大帧间隔需要完整的帧记录；眼镜显示帧率和 GPU 利用率需要在目标设备上测量。
