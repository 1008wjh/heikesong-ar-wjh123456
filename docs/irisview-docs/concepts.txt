浏览接口核心概念
窗口关联一个渲染根节点。将文字、图片和容器挂到根节点下，组成界面。

应用逻辑
状态与内容→宿主侧
布局与提交→显示侧
绘制与合成
宿主是运行应用的手机或电脑。应用在宿主上处理业务与排版，将场景更新交给眼镜或模拟器的显示执行框架。两端须支持对应接口和资源格式。
从窗口到图元
Window | 由 WindowProperty 描述并创建的应用窗口。 | 
FusionRoot | 从窗口获取渲染树入口，访问根 Widget，跟踪呈现。 | 
Board / View | 组织画布、容器与基础视图。 | 
Text / Image | 放置文字与图片，使用 Style 设置外观。 | 
应用身份 | manifest 的 ID 标识应用，version 和 versionCode 标识版本；画面标题由代码设置。 | 

对象由工厂 API 创建
使用 Text.create()、Board.create() 等工厂方法创建对象，并在使用期间保留引用。声明中的继承关系用于描述接口，不提供直接 new 原生对象或原生子类的能力。
版本与能力
Kit 版本标识开发工具。应用使用 version 和 versionCode 标识版本，使用 minimumHostVersion 声明所需的最低 Host API 版本。可用功能取决于目标设备和后端。
