浏览接口管理应用生命周期
应用进入后台后，前台更新任务应暂停，需要恢复的状态应保留。将创建、暂停、恢复和清理放到对应回调中，避免重复启动任务或遗留对象。
ON_CREATE | 创建窗口、状态与初始视图。 | 
ON_FOREGROUND / ON_REOPEN | 恢复需要前台执行的更新；避免重复注册回调。 | 
ON_BACKGROUND | 暂停前台动画、输入轮询和自动刷新等任务。 | 
ON_DESTROY | 取消回调，释放应用持有的对象与输入会话。 | 

呼吸示例的计时方式
active 记录应用是否在前台，frame 保存动画回调句柄。进入后台时取消回调；返回前台时重设计时起点，继续累计前台运行时间。计时使用 performance.now()，不受系统日期调整影响。
复制function pause() {
 active = false;
 if (frame !== null) os.cancelAnimationFrame(frame);
 frame = null;
}
// 在生命周期处理函数中调用；active、frame 与 os 由应用维护。
输入会话与异步请求
后台、销毁和断连可能撤销输入。已发出的网络请求仍可能返回，回调中应检查应用状态和请求顺序。音频会话需持续读取事件，直到收到 end；队列暂空仅表示当前无可读事件。
