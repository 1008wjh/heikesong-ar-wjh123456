呼吸 DemoAPI 参考
浏览接口保存应用数据
将设置和进度写入应用私有目录，以便下次启动时恢复。读取旧存档时，按数据版本迁移。
目录由 Host 提供
JavaScript 启动前，Host 设置 FUSIONUI_APP_DATA_DIR，为当前应用 ID 提供绝对、可写、隔离的目录。模拟器、Ubuntu 与 Android 的实际路径可以不同。
使用模板辅助函数
使用模板 src/application-data.js 中的 applicationDataPath(...) 拼接文件路径；自行实现时，需校验相对路径。不要从 Kit 安装目录、当前工作目录或用户 Home 推导业务存储路径。
格式和迁移由应用负责
应用需定义文件格式、默认值、读取失败处理和升级迁移。普通重启和升级通常保留应用数据；卸载时可选择删除，重要数据仍需单独备份。
区分持久与临时文件
临时文件使用 Node os.tmpdir()，长期设置使用应用私有目录。呼吸 Demo 不保存用户数据。
应用持久数据契约 →检查数据恢复
保存设置，结束应用并重新启动，检查设置是否恢复。分别测试首次启动、文件无法读取和旧格式迁移。
