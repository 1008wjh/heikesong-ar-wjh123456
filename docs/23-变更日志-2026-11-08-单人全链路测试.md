## 这次测了什么

前提：wjh 的声纹已经在库里（`voice_count=1`），识别人会先剔除主人那一簇。

跑的是 `node test/glasses_sim.js`，覆盖单人模式整条链路：

| 步骤 | HUD 实测 |
|---|---|
| 按一下 → 选单人 | 选模式页 |
| 进入在听 | `> 识别人 / 录 20 秒来找人` |
| 确认 → 录一段 | `识别人 4/9`（测试把时长压到 9 秒） |
| 认出熟人 | `认出 王姐 / 王姐 / 产品经理·前同事 / SIM 0.93` |
| 先停档案 | `先看档案 · 按钮 5 秒后出现` |
| 5 秒后出按钮 | `> 提词 / 待办事项 / 以前` |
| 按「提词」（这段已经没新音频） | `在想…` → `回复 · 45s`，模型回 `明天三点我准时到 / 电脑充电器我… / 会议室在三楼哪间` |
| 返回 | 待机 + 归档卡（不再显示假 SIM） |
| 第二段换陌生人 | `认出 陌生人A`，不再沿用王姐 |

单独打接口（主人声纹在库时）：

```json
{"ok":true,"status":"known","name":"王姐","similarity":0.919,
 "clusters":[{"speaker":1,"secs":6.08,"sim_owner":-0.041,"person":"王姐","sim":0.919}]}
```

`sim_owner=-0.041` 说明主人剔除在生效，但不会误删对方那一簇。

## 顺带修掉的一处

按按钮之后的回复卡、结束时的归档卡是 `pinned`（沿用已认出的人），相似度硬编码 1.0。
以前会显示 `SIM 1.00`，看着像"完美匹配"。现在 `agentCard` 带上 `matched_by`，
`pinned` 的卡片不显示 SIM。识别人那一次的卡仍然显示真实分数（上面是 0.93）。
