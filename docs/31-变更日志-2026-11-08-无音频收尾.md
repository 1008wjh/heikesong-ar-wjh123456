## 行为

```
按确认 → 开始识别人（20 秒）
   ├─ 有声音：正常分轨认人
   └─ 整段没声音（没麦克风 / 设备静音 / 平台没给帧）
        → 20 秒到点自动收尾
        → 状态行提示「没录到声音 · 3 秒后回到识别人」
        → 页面回到「> 识别人 / 录 20 秒来找人」
        → 再按确认 = 重新录
```

之前的问题：`finishIdentify()` 只在 `pump()` 的**音频分支**里按时间触发，
一帧音频都收不到时永远等不到收尾，状态行会停在 `N/20`。

## 改法

```js
// pump()：每拍都查一次 deadline，不再依赖音频事件
if (c.identifying && Date.now() - c.identAt >= IDENTIFY_MS) finishIdentify(c);

// finishIdentify()：没有音频
if (!chunks.length) {
  c.identified = null;
  c.buttonsAt = 0;
  paintListening("没录到声音 · 3 秒后回到识别人", 3000);
  return;
}
```

`paintListening(msg, holdMs)` 新增第二个参数（默认还是 4 秒）。
