## 说明与边界

- 「服务失败」用例里，静音音频是**真实失败路径**（非注入）；模型 503 / 坏 JSON 是
  **注入测试**（单元测试模拟 HTTP 失败），两者都注明了。
- 「过期数据」现在有明确出口：被新请求顶掉的慢请求返回「这条结果已过期」且不写
  `/api/latest`；取消返回「已取消」。
- 「演示数据」目前靠文档声明（人物库里的 50 条是构造数据）；如果要把"真实/演示"也做进
  界面，需要再加一个来源标记（未做）。
- 本轮同时加了两个稳健性修复：静音音频跳过转写（不再让模型在静音上编字）、
  同 session 请求序号（旧请求作废、不写档案、不覆盖 latest）。
